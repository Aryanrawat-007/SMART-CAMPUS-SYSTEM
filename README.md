# SMART-CAMPUS-SYSTEM

Smart Campus System is a C++-based Project-Based Learning (PBL) project designed to simplify and organize campus-related activities through a menu-driven application. This project demonstrates the practical implementation of Object-Oriented Programming (OOP) concepts, including classes, objects, encapsulation, constructors, and functions, along with Data Structures (DS) concepts such as arrays, searching, linked lists, stacks, and queues. It aims to provide an organized way to manage campus information while improving programming, problem-solving, and logical thinking skills. The project combines theoretical knowledge with practical implementation, demonstrating how C++ programming and data structures can be used to develop efficient, structured, and user-friendly applications for a smart campus environment.
