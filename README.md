📌 Project Overview

The Smart Campus and Student Support System is a C++-based application developed to make essential college information and student support services easily accessible through a single, menu-driven system. The project combines multiple campus-related modules, including Teacher Finding, College Problem Management, Club Information, Lost and Found, and Notices and Announcements.

The project also demonstrates the practical application of Data Structures and Algorithms (DSA), particularly linked lists, stacks, and queues, to organize records and manage campus information efficiently.

⚡ Features

* Teacher Finding: Search and view faculty details, including department, subject, and room information.
* College Problem Management: Maintain records of college-related complaints.
* Club Information: Access information about college clubs and their activities.
* Lost and Found: Manage records of lost and found items.
* Notices and Announcements: Organize and access important college notices.
* Menu-Driven Interface: Navigate between different modules through a central menu.
* Input Handling: Improve user input validation and menu selection.

🧠 Data Structures Used

🔸 Linked List

* Supports dynamic storage and management of records.
* Allows records to be added, searched, or deleted where required.

🔸 Queue

* Used in the notice system to demonstrate First In, First Out (FIFO) processing.
* Helps organize information in a defined order.

🔸 Stack

* Demonstrates Last In, First Out (LIFO) operations.
* Can support suitable operations requiring stack-based processing.

▶️ How to Run the Project

1️⃣ Clone the Repository

git clone https://github.com/Aryanrawat-007/SMART-CAMPUS-SYSTEM.git

2️⃣ Open the Project

Open the downloaded project folder in VS Code or another C++ IDE.

3️⃣ Compile the C++ Program

If the main source file is named main.cpp, run:

g++ main.cpp -o smart_campus

4️⃣ Run the Application

On Windows:

smart_campus.exe

On Linux or macOS:

./smart_campus

Note: Replace main.cpp with the actual main source filename if it is different.
